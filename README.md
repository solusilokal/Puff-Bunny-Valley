# Puff Bunny Valley 🐰🌸

Mini Website Ekowisata & Taman Bermain Kelinci - **Puff Bunny Valley**.

## Fitur Utama
- **Profil & Header Menarik**: Dilengkapi dengan logo resmi dan latar belakang alam lembah kelinci.
- **Katalog Aktivitas Seru**: Feeding time, petting zoo, bunny playground, dan photo studio.
- **Galeri Foto Interaktif**: Dilengkapi slider horizontal *scroll-snap* dan pop-up *lightbox modal*.
- **Pilihan Paket Tiket**: Transparan dan mudah dipahami.
- **Form Reservasi WhatsApp**: Terintegrasi otomatis untuk mengirim format booking langsung ke WhatsApp admin.
- **FAQ Accordion & Ulasan**: Jawaban pertanyaan umum dan testimoni pengunjung.
- **Fitur Bagikan & Salin Tautan**: Share langsung ke WhatsApp, Twitter (X), atau salin tautan.

## Teknologi
- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Cara Menjalankan Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/solusilokal/Puff-Bunny-Valley.git
   cd Puff-Bunny-Valley
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173`.

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```
